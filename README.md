# Task Manager API

A simple CRUD (Create, Read, Update, Delete) API built using Python, Flask, and SQLite for the SkillPilot project.

## Features
- Create a new task (POST)
- View all tasks (GET)
- Update an existing task (PUT)
- Delete a task (DELETE)

## Technologies Used
- Python
- Flask
- SQLite (built-in)

1. Clone the repository or download the files.
2. Open the terminal in the project folder.
